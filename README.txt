# The Patchy Burger — Premium & Elegant Redesign

## Included files
- `index.html` — complete page structure and menu content
- `assets/css/styles.css` — premium visual design, responsive layout, animations
- `assets/js/main.js` — mobile navigation, menu filters, animated reveals, and demo shopping cart

## Setup
1. Make a backup of your existing website folder.
2. Copy `index.html` into your website's root folder (use your current homepage filename if your server expects a different name).
3. Replace `assets/css/styles.css` with the included CSS.
4. Replace `assets/js/main.js` with the included JavaScript.
5. Keep the paths exactly as shown: `assets/css/styles.css` and `assets/js/main.js`.
6. Open `index.html` in your browser, or run the folder through VS Code Live Server.

## Before publishing
- The menu names, PHP prices, photos, and review text are examples. Replace them with your actual menu and genuine customer reviews.
- Update the email, location, opening hours, and social links in the footer.
- The cart is front-end only: it updates quantities and totals but does not process payments or submit an order. Connect the checkout button to your real ordering service/backend before accepting orders.
- Images, Google Fonts, and Lucide icons load from external services and require an internet connection.
- This design uses the existing `assets/css` and `assets/js` folder structure. The old `assets/js/script.js` is not required by this version; remove its script tag if you keep the old file.
